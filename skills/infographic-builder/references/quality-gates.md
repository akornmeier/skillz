# Quality gates

Review the artifact at intended size and in its delivery context. Record pass, fail, not applicable, or not run—never imply a check happened when it did not.

## 1. Evidence

- [ ] Every factual element maps to a claim ID and source.
- [ ] Values, units, dates, geographies, populations, and denominators match the source.
- [ ] Derived values and rounding were independently recomputed.
- [ ] Observed, estimated, and projected values are distinguished.
- [ ] Conflicting or weak sources are disclosed.
- [ ] Sources and access dates are legible.
- [ ] No generated illustration introduces an apparent factual claim.

## 2. Visual semantics

- [ ] The visual form answers the stated question.
- [ ] Axes, scales, baselines, bins, and symbol areas are honest.
- [ ] Missing data is distinct from zero.
- [ ] Labels, legends, and annotations refer to the correct marks.
- [ ] Ordering is intentional; timelines and numbered steps are correct.
- [ ] Decorative geometry cannot be mistaken for quantity.
- [ ] Maps use correct geography and normalization where needed.

## 3. Narrative

- [ ] The main message is supportable in one sentence.
- [ ] The headline does not overstate causality, certainty, or scope.
- [ ] The first ten seconds reveal the intended takeaway.
- [ ] Supporting panels advance one story rather than competing stories.
- [ ] A material caveat is visible near the affected claim.
- [ ] The implication/action follows from the evidence.

## 4. Layout and craft

- [ ] Reading order is unambiguous.
- [ ] Primary, secondary, and tertiary hierarchy is visible.
- [ ] Alignment, spacing, and grouping are consistent.
- [ ] Text and sources are readable at actual delivery size.
- [ ] Direct labels are used where they reduce lookup.
- [ ] Color roles are consistent and restrained.
- [ ] Export has no clipping, missing fonts/assets, or broken links.
- [ ] Narrow/wide layouts were tested when responsive.

## 5. Accessibility

- [ ] The visual has a useful title and description.
- [ ] A text alternative communicates the conclusion, evidence, and caveat.
- [ ] Exact values are available in text/table when necessary.
- [ ] Color is not the only carrier of meaning.
- [ ] Text and essential graphics meet the project's contrast target.
- [ ] Reading order is sensible to assistive technology.
- [ ] Interactive controls work with keyboard and touch.
- [ ] Reduced-motion behavior preserves understanding.

## 6. External generation

- [ ] User approval and data-sharing permission were recorded.
- [ ] Cost was estimated/approved before generation.
- [ ] Model/workflow, prompt, parameters, job ID, and asset path were captured.
- [ ] Generated text, numbers, symbols, logos, and imagery were manually inspected.
- [ ] Verified information remains in a deterministic editable layer.
- [ ] A fallback exists if the generated asset is removed.
